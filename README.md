# Açaí da Hora

Vitrine mobile-first para delivery, construída em HTML, CSS e JavaScript sem dependências de interface.

## Executar localmente

```powershell
npm install
npm run dev
```

Para gerar a versão de produção:

```powershell
npm run build
```

## Recursos incluídos

- Catálogo compacto, responsivo e com imagens carregadas sob demanda.
- Modal de montagem com até cinco adicionais grátis, adicionais premium e preço atualizado em tempo real.
- Carrinho fixo no mobile e painel de pedido.
- Localização aproximada por IP via `ipwho.is`, em carregamento assíncrono e sem solicitar a localização do navegador.

> Antes de publicar, inclua uma referência clara a esse tratamento de localização aproximada na política de privacidade. O próximo passo será substituir a finalização demonstrativa pela integração segura com a UmbrellaPag.
